# ลบรูป By จ๊าบ

แอปลบรูปแบบปัด + หารูปซ้ำ/ไม่ชัด/เสีย + ย้ายรูปไป Google Drive

| ปัด | ผล |
|---|---|
| ⬅ ซ้าย | เก็บไว้ในเครื่อง |
| ➡ ขวา | ลบ (เข้าแท็บ “ที่ลบ” กู้คืนได้ / ลบถาวรได้) |
| ⬇ ลง | อัปโหลดขึ้น Google Drive แล้วลบออกจากมือถือ |

## ทดสอบในเบราว์เซอร์
เปิด `www/index.html` ได้เลย (โหมด TEST: รูปจำลอง, Drive จำลอง)
หรือ `npm run serve` แล้วเปิด http://localhost:8080

## สร้าง APK ด้วย GitHub
1. สร้าง repo ใหม่ แล้ว push ทุกไฟล์ในโฟลเดอร์นี้ขึ้น branch `main`
2. ไปแท็บ **Actions** → workflow **Build APK** จะรันเอง (หรือกด Run workflow)
3. รอเสร็จ (~5-8 นาที) → ดาวน์โหลด artifact **SwipeClean-apk** → ได้ `app-debug.apk`
4. ลง APK บนมือถือ (เปิด “ติดตั้งจากแหล่งที่ไม่รู้จัก”)

ต้องใช้ Android 11 ขึ้นไป (ใช้ระบบยืนยันลบรูปของ Android)

## ตั้งค่า Google Drive
1. Google Cloud Console → สร้างโปรเจกต์ → เปิดใช้ **Google Drive API**
2. OAuth consent screen → ใส่อีเมลตัวเองเป็น Test user
3. Credentials → Create OAuth client ID → ประเภท **TVs and Limited Input devices**
4. เปิดแอป → ⚙ ตั้งค่า → ใส่ Client ID / Secret → “เชื่อม Google Drive”
5. เปิดลิงก์ที่แอปแสดง แล้วใส่รหัส ระบบจะเชื่อมให้อัตโนมัติ

รูปไปอยู่ในโฟลเดอร์ `รูปจากมือถือ` บน Drive

## ฟอนต์
ใช้ฟอนต์ Mali (น่ารัก วัยรุ่น) workflow จะคัดลอกเข้า APK ให้เอง ใช้ออฟไลน์ได้
ทดสอบในเบราว์เซอร์: ถ้าออนไลน์จะโหลดจาก Google Fonts เอง ถ้าอยากใช้ไฟล์ในเครื่อง: `npm install && npm run fonts`

## หมายเหตุ
- ปัดลง: อัปโหลดสำเร็จก่อนถึงจะลบในเครื่อง ถ้าอัปโหลดล้มเหลวรูปไม่หาย
- Android ถามยืนยันลบเป็นชุด (ครบ 8 รูป หรือกดป้ายสีส้มด้านบน)
- สแกนรูปทำในเครื่อง ไม่ส่งรูปไปไหน ปรับจำนวนรูปที่สแกนได้ในแท็บสแกน
- APK เป็น debug (ติดตั้งได้ทันที) ถ้าจะขึ้น Play Store ต้องเพิ่ม release signing
